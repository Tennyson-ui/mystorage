# Pontos de interesse

Esta pasta recebera futuramente pontos de exutorio ou locais de interesse para analise SWOT.

Formato CSV sugerido:

```csv
id,longitude,latitude
```

Campos previstos:

- `id`: identificador unico do ponto.
- `longitude`: longitude em graus decimais.
- `latitude`: latitude em graus decimais.

Nao foram criados dados ficticios nesta etapa.
